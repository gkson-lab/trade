    1Price data in

    One CSV per symbol (a Yahoo Finance download works: Date, Open, High, Low, Close, Adj Close, Volume), or one CSV with a symbol column. A .zip of CSVs works too. Several years of daily prices for 20 or more symbols give the bot something to learn from.

    3Train and test

    The bot trains on the oldest 70% of dates, tunes on the next 15%, and is scored on the newest 15%, which it never sees while learning. Every trade enters at the next day's open, so nothing uses information it couldn't have had.

    Trading data bot

    Sends the data your bots collect to the internal documents repository as a pull request, under your GitHub account. It lands in shelf-12-trading-data/ with a confidential header and document ID, following the repository's handling rules.

    What to send
    Kept only in this browser and sent only to api.github.com. Never saved to any repository.
    How to make a token
    1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens, and choose Generate new token.
    2. Resource owner: gk-research-group. Repository access: only internal-documents-.
    3. Repository permissions: Contents read and write, Pull requests read and write. Nothing else.
    4. If the organization requires approval for fine-grained tokens, approve it as an owner.
    In endless runs the run's pull request is also updated every generations.
    GitHub's upload page

    No token, or GitHub blocked on this page? Download the bundle, open GitHub's upload page, drop the files in, and pick "Create a new branch and start a pull request".
